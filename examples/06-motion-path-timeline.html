06 · A marker following a drawn path down a timeline

Two plugins working together. DrawSVGPlugin draws the route in as you scroll. MotionPathPlugin moves a marker (here a ball) along that same <path>. Year labels fade in as it reaches them. All scrubbed, so it runs backwards too. A route on a map, a journey, a river, a life: same two plugins.

To use your own route: draw a path in Illustrator, Figma or Inkscape, export as SVG, and paste the d="…" value into the path below. Keep it inside the same viewBox.
